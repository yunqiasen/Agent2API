# 调用密钥的模型范围与倍率展示边界

2026-10-08 对齐：历史 Key 保持不限模型以兼容既有调用方，新建 Key 显式选择「不限模型」或非空的「指定模型」白名单；白名单固定为管理员选择的模型 ID，新模型不自动获得许可。已有 Key 支持编辑渠道及模型范围而保留原密钥，外部模型清单取密钥许可、渠道绑定与全局开关的交集，避免把后台完整目录当作密钥权限。倍率只在管理模型界面按渠道显示「免费 / ×倍率 / 未公布」，`/v1/models` 保持原响应结构而按权限过滤，不把随渠道变化的价格塞进跨渠道公共模型条目。

模型权限以实际调用为准：显式选择、系统默认选择及内部模型替换都遵守同一密钥范围；后台目录过滤只是展示，实际请求也执行同一限制。缺省字段处理属于内部兼容细节，不单独增加用户配置。

Key 多选区直接服从模型页全局开关：在所选渠道范围内关闭的模型保留显示但灰显、不可点击；开启但尚未加入该 Key 的模型仍可选择。候选展示、保存校验与实际调用采用同一生效范围，避免只有界面限制而权限脱节。
